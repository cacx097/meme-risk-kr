# 공개 홍보 문구 초안 (한국어)

규칙: "안전", "수익", "추천", "매수" 같은 말을 쓰지 않는다. 안내 문구를 항상 붙인다.

## 1. 텔레그램 커뮤니티용 (짧게)

엘리시움(Montra)·솔라나·베이스 밈코인, 사기 전에 주소 한 번 넣어보세요.

@MemeRiskKR_bot 에 토큰 주소를 보내면 몇 초 안에 알려드립니다.
- 개발자 지갑이 전에 만든 토큰이 몇 개고 몇 개가 죽었는지
- 개발자·상위 지갑이 얼마나 들고 있는지
- 거래 수수료가 몇 %인지, 나중에 바꿀 수 있는지
- (솔라나) 개발자가 토큰을 더 찍어내거나 지갑을 동결할 수 있는지
- (베이스) 사고 나서 팔 수 있는 토큰인지, 개발자가 거래를 멈추거나 코드를 바꿀 수 있는지
- 이름만 베낀 가짜 토큰인지

그룹에 넣어두면 누가 주소를 올릴 때 자동으로 요약합니다.
무료이고 지갑 연결이 필요 없습니다. 점수 계산 방법은 전부 공개합니다.

※ 투자 조언이 아닌 공개 데이터 기반 참고 정보입니다.

## 2. X(트위터)용

🪞 이름 베낀 가짜 토큰
